# Support

## Usage and development questions

Use a GitHub issue or discussion in `joinotto/rivet` for:

- Installation and local-use questions.
- Unexpected command behavior.
- Documentation gaps.
- Feature proposals.
- Reproducible defects that do not disclose a new vulnerability.

Include the Rivet revision, host, model provider when relevant, operating
system, Node.js version, command, redacted output, and a small reproduction.

Rivet is in early development. The project does not provide a response-time
guarantee or paid support channel.

## Security reports

Do not report a new vulnerability through a public support issue. Follow
`SECURITY.md` and use GitHub private vulnerability reporting.

## Unsupported requests

Maintainers cannot authorize testing against a system that the requester does
not own or control. Rivet support does not provide compliance certification,
production incident command, exploit development, or a guarantee that a
system is secure.
