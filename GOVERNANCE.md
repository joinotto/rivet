# Governance

> This document uses an ASD-STE100-aligned technical writing style. It is not a certified ASD-STE100 document.

## Current stage

The project is founder-led during initial development.

## Decision rules

- Make product and technical decisions in public project records.
- Require two reviewers for security-sensitive release code when two qualified reviewers are available.
- Record incompatible interface decisions.
- Record conflicts of interest.
- Do not give an undocumented veto to a person or company.

## Maintainers

Maintainers can:

- Triage issues.
- Review and merge changes.
- Prepare releases.
- Respond to security reports.

The project must publish a named maintainer list before its first public release.

## Maintainer changes

A new maintainer must have:

- Sustained project contributions.
- Sound technical judgment.
- Responsible security behavior.
- Agreement from current maintainers.

The project must record maintainer additions and removals.

## Future governance

Before the project has several organizations as regular contributors, define:

- A technical steering process.
- An appeal process.
- A maintainer succession process.
- A trademark policy.
- A sponsorship and budget policy.
